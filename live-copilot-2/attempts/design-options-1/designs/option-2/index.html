    Folio iii · Colophon of Agents Who set this type, and by what rule

    On the Hands Behind the Draft

    Nothing in this file writes itself anonymously. A draft passes through several hands before it reaches you: a retriever that searches the indexed corpus, a drafter that composes an answer strictly from the passages it was given, and a verifier that checks each claim against its citation before the draft is entered into the thread.

    We publish that list rather than hide it. If you are to be accountable for approving a reply, you are owed a plain account of how it was assembled — which tools each agent may call, and which evaluations it must pass before its output is shown to you at all.

    An assistant you cannot inspect is an assistant you cannot answer for. Every agent below is named, scoped and tested.

    Awaiting Disposition

    Drafts are listed in the order they were retrieved. Each must be read and given a decision by a named analyst; an unapproved draft has no route out of this application.

    • Pending — read, not yet decided
    • Approved — sent as drafted
    • Edited — amended, then approved
    • Rejected — withheld, reason filed
    §

    Audit trail. Each decision writes an immutable line to the record: who decided, at what hour, and whether the draft was edited before it was sent. The automated-assistant disclosure travels with the reply regardless of the decision taken.
