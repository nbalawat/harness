# KYC Review Desk

Generated by the harness `agentic-app` project type.

## Run locally

```
docker compose up
# backend: http://localhost:8000  frontend: http://localhost:8080
```

## Layout

- `backend/` — FastAPI app (health, chat, table CRUD)
- `frontend/` — chat-shell UI with approved design tokens
- `agents/` — agent roster + eval suite (`python3 agents/run_evals.py`)
- `composed_modules.json` — certified modules composed into this app
