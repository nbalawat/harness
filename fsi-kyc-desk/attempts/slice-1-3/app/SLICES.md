# KYC Review Desk — slices

- **Slice 1 — Case intake and deterministic completeness check** (`case-intake-completeness`; REQ-001…REQ-014, REQ-055, REQ-070, REQ-089, REQ-094). A submission opens a case and runs the approved `case-intake-and-risk-scoring` workflow through `workflow_engine` — handlers `open_case_from_submission`, `run_document_completeness_check`, `mark_case_ready`, `compute_risk_score_from_matrix`, `start_sla_clock` and `return_case_with_missing_documents` are registered at import in `backend/ext_cases.py`. The package is checked mechanically against versioned Document Checklist v2.0 (`backend/kyc_policy.py`), including conditional items for deep ownership chains, regulated industries and expected cross-border activity: a complete package moves the case to `ready` with a case-ready timestamp, an incomplete one is `returned` with the itemised `missing_documents` list plus a notification to the submitter. No role may waive a required item — `POST /cases/{ref}/waive-document` always refuses with 403 and records the refusal on the trail. Cases are addressed case-insensitively by submission reference. Endpoints, all registered outside `/api/` so the `/api/{table}` catch-all cannot shadow them: `GET /checklist`, `POST /cases`, `GET /cases`, `GET /cases/{reference}`, `POST /cases/{reference}/waive-document`. Storage is `db.store` only (`cases`, `documents`, `missing_documents`, `notifications`, `audit_trail`, `risk_scores`, `sla_tracking`, `users`); every state change writes an `audit_trail` row via `ext_audit.record`. UI: a live intake form and register table added inside the design's existing `#screen-worklist`, and a live case file showing the mechanical completeness result and outstanding-item list inside `#screen-case` — both built from the Dossier design's own classes and `tokens.css` variables, `textContent` only, with `cases.js` added alongside the untouched `app.js`. Also registered the chat-shell/seed-data `conversations` table in `models.TABLES`, which the pre-existing `test_table_crud` test requires (the suite was red before this slice).
