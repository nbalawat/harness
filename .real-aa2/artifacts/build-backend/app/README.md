# Support Copilot

Generated by the harness `agentic-app` project type.

## Run locally

```
docker compose up
# backend: http://localhost:8000  frontend: http://localhost:8080
```

## Layout

- `backend/` — FastAPI app (health, chat, table CRUD)
- `frontend/` — chat-shell UI with approved design tokens
- `agents/` — agent roster + eval suite (`python3 agents/run_evals.py`)
  - `agents/roster.json` is currently a bootstrap placeholder written by the
    backend build so the composed `agent-runtime` module is runnable. The
    `build-agents` node replaces it with the approved `agent_roster.json` and
    adds `agents/evals/cases.json`.
- `backend/models.py` — `TABLES`, generated from the approved `data_model.json`
- `composed_modules.json` — certified modules composed into this app
